# FRE(Fractal Recursive Encryption)
chiffrement asymétrique a 2 clé, une publique et une privé, utilise de multiplie chiffrement incorporer pour une sécurité maximale post-quantique, utilisant AES256, Kyber1024, Base64, Hex sous forme diverses pour garantir la sécurité, si un de ses chiffrement est cassé cela n'est néanmoins pas déchiffrable.
